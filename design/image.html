What is context engineering in large language models?13:17
R

Context engineering refers to the deliberate design, selection, and arrangement of information provided to large language models to improve the quality, reliability, and relevance of their outputs. Rather than relying solely on model parameters or fine-tuning, it treats the input context as a controllable interface.

Key aspects include selecting the right pieces of information, ordering them to match the model's attention patterns, and formatting the context to reduce ambiguity. Common techniques include retrieval augmentation, structured prompts, memory management, and dynamic context assembly.

How is it different from prompt engineering?13:18
R

Prompt engineering focuses on crafting the instruction or query to elicit the desired behavior. Context engineering is the broader discipline of what information is provided, how it's structured, and how it changes over time — designing the whole environment the request is interpreted in.
