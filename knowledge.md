# STYLE GUIDE

## COLOUR PALETTE

Primary
• Deep Navy: #1A1F2E
• Burnt Orange: #E8590C
• Warm Gray: #8B8B8B

Neutral
• Off-White: #F5F5F5
• Light Gray: #E8E8E8
• Dark Gray: #4A4A4A
• Black: #000000

Accent
• Soft Blue (secondary): #3A5A7A
• Orange accent (hover): #FF6B1A

## TYPOGRAPHY

Font Families
• Headings: Courier Prime, monospace (for names/titles)
• Body: -apple-system, BlinkMacSystemFont, Segoe UI, Roboto, sans-serif
• Monospace accents: IBM Plex Mono

Type Scale
• H1 (page title): 32px, weight 400, line-height 1.3
• H2 (section headers): 24px, weight 400, line-height 1.4
• H3 (subsection): 18px, weight 400, line-height 1.4
• Body: 14px, weight 400, line-height 1.6
• Caption/meta: 12px, weight 400, line-height 1.5, color #8B8B8B
• Tags/labels: 11px, weight 400, uppercase letter-spacing 0.5px

## SPACING & LAYOUT

Density
• Minimal, breathing layout with generous whitespace
• Content centers with max-width 800px for readability
• Sidebar navigation: fixed left column, ~120px wide

Base Unit: 8px grid

Margins & Padding
• Page margins: 40px top/bottom, 32px left/right (desktop)
• Section padding: 48px vertical, 32px horizontal
• Card padding: 24px
• Component padding: 12px–16px

## BORDER RADIUS

• Buttons & cards: 4px (subtle, squared)
• Profile/avatar images: 8px (slightly rounded)
• Hero/featured images: 0px (sharp)

## SHADOWS & ELEVATION

• Subtle elevation for cards: 0 2px 8px rgba(0, 0, 0, 0.08)
• Hover state elevation: 0 4px 12px rgba(0, 0, 0, 0.12)
• No heavy shadows; maintain flat, minimal aesthetic

## BUTTONS & COMPONENTS

Buttons
• Primary: Background #E8590C, text #FFFFFF, padding 10px 20px, border-radius 4px, font-weight 400
• Secondary: Border 1px #8B8B8B, text #1A1F2E, background transparent, padding 10px 20px
• Hover: Opacity 0.85, shadow 0 2px 8px rgba(232, 89, 12, 0.2)
• Active/focus: Outline 2px solid #E8590C, outline-offset 2px

Icon Buttons
• Size: 24px × 24px or 32px × 32px
• Color: #4A4A4A, hover #E8590C
• Background: transparent, hover light-gray #F5F5F5

Links
• Color: #E8590C
• Underline: 1px solid (on hover)
• No underline by default

Input Fields
• Border: 1px solid #E8E8E8
• Background: #FFFFFF
• Padding: 10px 12px
• Focus: Border #E8590C, box-shadow 0 0 0 2px rgba(232, 89, 12, 0.1)
• Font: 14px, #1A1F2E

## ICONOGRAPHY

Style
• Minimal, stroke-based icons
• Weight: 1.5px–2px stroke
• Size: 16px (inline), 24px (UI), 32px (featured)
• Color: #4A4A4A (default), #E8590C (active/hover)
• Spacing: Minimum 8px around icons

Sources: Feather Icons or custom hand-drawn minimalist approach

## IMAGERY TREATMENT

Photography
• High contrast, atmospheric black & white or desaturated
• Overlaid with subtle grain texture
• Cropped tightly to focal point
• Border-radius: 0px (sharp edges for drama)

Featured Images
• Full-width or column-spanning
• Aspect ratio: 16:9 (wide hero), 4:3 (card thumbnails)
• Overlay text in white with subtle drop shadow

Illustration
• Minimal line-based or monochromatic
• Color accent: Burnt orange (#E8590C) for highlights
• Consistent stroke weight 1.5–2px

## VOICE & TONE FOR UI COPY

Tone
• Direct and technical without jargon
• Professional but approachable
• Honest, outcome-focused language
• Avoid marketing clichés

Button & CTA Copy
• Imperative: "View Work", "Read More", "Get Started"
• Short, action-oriented phrases (2–3 words max)
• Capitalize first word only

Microcopy
• Labels: lowercase unless proper nouns ("Email address", "Project name")
• Placeholder text: 12px, #8B8B8B, italic (optional)
• Error messages: Clear, specific, and constructive ("Email required" not "Error")
• Empty states: Brief, encouraging prompt with next step

Navigation Labels
• Concise: "Home", "Work", "Blog", "Contact"
• Meta descriptions: Small caps or subtle italic, 12px, #8B8B8B

## ADDITIONAL NOTES

Layout Grid
• Desktop: 12-column grid with 32px gutter
• Tablet (768px–1024px): 8-column grid, 24px gutter
• Mobile (<768px): Single column, 16px margin

Spacing Rhythm
• Use 8px, 16px, 24px, 32px, 48px for consistency
• Never use arbitrary spacing

Animation
• Transitions: 200ms ease-out (hover states, link underlines)
• No auto-play animations; user-triggered only
• Fade-in for page loads: 300ms ease-in

Accessibility
• Minimum contrast ratio 4.5:1 for body text
• Focus indicators: 2px solid #E8590C outline
• All interactive elements keyboard-accessible
• Alt text: Descriptive, not repetitive

Dark Mode (Optional)
• Background: #0F1419
• Text: #F5F5F5
• Accents: #FF6B1A (warmer orange for contrast)
• Borders: #2A2F3E
